6. Proposed Methodology
The proposed system follows a step-by-step data processing, probabilistic reasoning, fuzzy
inferencing, and visualization pipeline.

​
Brief Description of Each Step
●​ Data Collection: A 30-day (720-hour) micro-climate time-series dataset
(smart_home_climate_data.csv) simulating tropical temperature swings ,sensor triggers,
and power grid status (Mains vs. Inverter) is generated.
●​ Data Preprocessing: Missing values are handled, continuous climate variables are
normalized, and textual human commands are lowercased, tokenized, and mapped to
domain features.
●​ Feature Selection: Key indicators impacting appliance power state—such as
ambient_temp, relative_humidity, motion_sensor, and grid_power—are isolated for
inferencing.
●​ Model Training & Fitting: ML models (Random Forest, Decision Trees, Naive Bayes,
KNN) and Fuzzy Rule bases are trained and fitted on the multi-modal dataset.
●​ Testing & Evaluation: System outputs are evaluated using multi-class metrics including
Accuracy, Precision, Recall, F1-Score, and Confusion Matrix visual maps.
●​ Digital Footprint & Energy Dashboard: Results, real-time slider simulations, grid
failover switches, and performance plots are served through an interactive Streamlit web
application.
